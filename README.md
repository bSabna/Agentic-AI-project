# Cotiviti Agentic AI — Intern Assessment

This repository contains the complete submission for the Cotiviti Intern Assessment, including the written report, presentation slides, demo video, and a working proof-of-concept (POC) application.

## 📁 Repository Structure

cotiviti-agentic-ai/
│
├── report/

│
├── ppt/
│   └── Sabna - AI_TPO.pptx                # Presentation slides
│
├── video/
│   └── README.md                          # Link to demo video (hosted on Google Drive)
│
├── poc/
│   ├── app.py                             # Main application
│   ├── requirements.txt                   # Python dependencies
│   ├── README.md                          # POC-specific documentation
│   ├── agents/                            # Agent modules (fraud, cost, coding, decision, etc.)
│   ├── data/                              # Sample healthcare knowledge base
│   └── rag/                               # RAG pipeline (retriever, vectorstore builder)
│
└── .gitignore

## 📄 Contents

- **Report** — Detailed write-up of the project, approach, and findings.
- **Presentation** — Slide deck summarizing the project for a non-technical audience.
- **Video** — Recorded demo walkthrough (see [`video/README.md`](video/README.md) for the link).
- **POC** — A working proof-of-concept implementing an agentic AI system for healthcare claims processing, including fraud detection, cost analysis, and RAG-based knowledge retrieval.
